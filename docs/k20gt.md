# 迈从 K20 GT 音箱歌词

SPlayer 可以通过 USB 将当前歌词发送到迈从 K20 GT 的屏幕，无需 Python 或额外的本地代理

## 使用

1. 通过 USB 连接 K20 GT
2. 在 MCHOSE HUB 中关闭歌词同步，避免两个程序覆盖屏幕内容
3. 打开 SPlayer 的「设置 → 外部歌词 → 迈从 K20 GT 音箱」
4. 开启「音箱歌词同步」，连接状态显示已连接后播放带有歌词的歌曲

支持原文、翻译和音译，缺少对应语言时显示原文。单页最多 52 个 UTF-8 字节，长句按当前行时长分成多页，保留完整 Unicode 字符。屏幕能否显示特殊符号取决于音箱字库

暂停时保留当前歌词，跳转、倍速和歌词偏移会更新显示。间奏、停止或无歌词时退出歌词显示通道。隐藏到托盘或离开设置页后继续同步，拔插设备会自动重连，通信失败时可点击「重新连接」。关闭功能或退出 SPlayer 时清屏并释放 USB 接口

## 实现

主进程订阅现有 `nowPlaying` 服务，仅保留当前曲目的分页文字与轻量播放锚点，播放期间每 100ms 选择当前页，只在内容变化时发送报文。暂停、无歌词、断开和关闭功能时停止定时任务

专用隐藏页面负责 WebHID 写入，使用独立的内存 session 和最小预加载接口。设备权限只授予该页面及 `3837:60C6` 设备，控制集合必须包含输出 Report `BC`。主窗口与其他歌词窗口继续沿用现有的隐藏窗口节流策略

设备写入串行执行，仅保留正在写入及最新待发的报文。关闭功能后销毁设备页面，取消播放订阅、设备监听和定时器。只有该功能启用时才创建额外的渲染进程

协议沿用「前期测试」中已验证的普通歌词命令 `0B`，没有更改设备固件、灯光或音量
