# 插件更新

插件通过 `@updateUrl` 发布更新。宿主检查远端脚本的 `@version`，发现新版后在插件卡片中提示，由用户点击更新。

## 声明更新信息

```js
/**
 * @name 示例插件
 * @id you.example
 * @version 1.1.0
 * @updateUrl https://example.com/plugins/example.js
 * @changelog 修复连接问题\n新增歌曲菜单
 */
```

| 字段         | 说明                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------- |
| `@updateUrl` | 最新原始 `.js` 文件的固定 HTTPS 地址；本地调试可使用 `http://localhost` 或 `http://127.0.0.1` |
| `@version`   | 按数字分段比较的版本号，发布新版时递增                                                        |
| `@changelog` | 新版更新说明，单行内用字面量 `\n` 换行                                                        |

更新机制不需要插件调用方法或声明额外权限。这里记录的是插件自身版本；宿主接口的级别变化见 [插件 API 级别](/plugins/changelog)。

## 检查与安装

应用启动时检查更新，用户也可在插件卡片中手动检查。未声明 `@updateUrl` 的插件不参与检查。更新说明取自远端新版脚本。

安装新版会替换脚本并重新加载插件，保留启用状态、权限选择、设置、私有存储和优先级。新版必须保持相同的 `@id`；未声明 `@id` 时，也要保持名称不变。

重新导入相同 ID 的脚本同样会替换已安装版本。

LX 脚本的更新提示见 [LX 兼容](/plugins/lx#update-alert)。
