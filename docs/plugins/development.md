# 插件开发

插件以单个 JavaScript 脚本交付，通过宿主提供的 `splayer` 对象调用接口。开发时不需要搭建 Electron 或 Vue 项目。

## 第一个插件

将以下内容保存为 `track-log.js`，通过**设置 → 插件管理 → 本地导入**安装。切换歌曲后，可在应用日志中看到曲目名称。

```js
/**
 * @name 曲目日志
 * @id you.track-log
 * @version 1.0.0
 * @description 记录当前播放的歌曲
 * @apiLevel 2
 */
splayer.register({ events: ["trackChange"] });
splayer.player.on("trackChange", ({ track }) => {
  if (track) splayer.log.info(track.title);
});
```

修改后重新导入同一个文件即可更新插件。发布新版时保持 `@id` 不变，并递增 `@version`。

## 选择能力

一个插件可同时提供音源、订阅播放事件、控制播放、声明设置和扩展菜单。按功能选择所需接口。

| 文档                                | 用途                                       |
| ----------------------------------- | ------------------------------------------ |
| [总览与架构](/plugins/)             | 脚本声明、运行环境、生命周期、权限和调试   |
| [插件 API 级别](/plugins/changelog) | 选择 `@apiLevel`，查阅接口演化             |
| [通用 API](/plugins/api)            | 搜索、平台接口、网络、数据存储、设置和菜单 |
| [音源解析](/plugins/source)         | 独立曲库搜索、播放地址、歌词、封面和评论   |
| [播放控制](/plugins/control)        | 订阅播放事件，操作播放、队列和播放模式     |
| [插件更新](/plugins/update)         | 发布版本和更新地址                         |
| [LX 兼容](/plugins/lx)              | 接入已有的 LX 脚本                         |
| [类型参考](/types)                  | `Track`、艺术家、歌词和评论的数据结构      |

`@apiLevel` 填写所用方法要求的最低级别。每个方法的文档都列出 API 版本与所需权限，权限通过脚本头的 `@grant` 声明。

## 开发流程

### 编写脚本

先声明插件信息，再注册能力和处理器。联网、搜索等耗时操作放入异步函数，通过 `splayer.log` 记录结果或错误。脚本的运行环境见[总览与架构](/plugins/#运行环境)。

### 本地验证

导入脚本后，确认插件状态为「已就绪」，再触发对应操作。播放事件可通过切歌或暂停验证；音源能力可通过播放其支持的来源验证；设置和菜单可在插件卡片及歌曲菜单中验证。

独立来源可按[完整示例](/plugins/source#快速开始)接入。验证搜索和分页、播放和入队，以及重启后的队列恢复；再检查歌词和缺失封面的补充。禁用插件时，已有队列中的歌曲应保留并提示来源不可用。

日志位于 `{userData}/app-data/logs/`。遇到错误时检查参数、权限和业务响应，定位方法见[调试](/plugins/#调试)。

### 发布更新

保留稳定的插件 ID，通过 `@updateUrl` 提供脚本下载地址，填写版本和更新说明。发布到市场的方式见[发布插件](/plugins/#发布插件)。

## Agent 辅助

### 提供上下文

推荐让 Agent 先读取文档，再生成或修改插件。可直接把以下链接交给它：

- [文档索引](/llms.txt)：按主题选择要读取的 Markdown 原文。
- [完整文档](/llms-full.txt)：文档的完整 Markdown 合集。

这些资料随文档构建自动生成，使用英文文档作为 Agent 的统一资料入口。

### 描述需求

说明插件要做什么、何时触发、有哪些设置，以及需要连接的服务。可以使用以下提示词：

```text
请先读取 https://splayer-next.imsyy.top/llms.txt 及与任务有关的文档，
为 SPlayer-Next 开发一个插件：

功能：歌曲切换时记录曲目名称，可在插件设置中关闭。
插件 ID：you.track-log
交付：可直接导入的单个 .js 文件，以及本地验证步骤。

根据当前文档选择 API 级别和权限，使用已有的 Track 结构。
```
