# SPlayer Next 隐私政策

**版本：v1.2**<br>
**生效日期：2026 年 8 月 5 日**<br>
**最近更新：2026 年 8 月 12 日**

欢迎使用 SPlayer Next（以下简称“本软件”或“我们”）。我们深知个人信息对您的重要性，并始终致力于保护您的隐私与数据安全。本隐私政策旨在向您清晰、透明地说明在您下载、安装、启动及使用本软件的过程中，我们如何处理、存储与保护您的个人信息，以及您所拥有的相关权利。

在您使用本软件前，请务必仔细阅读并充分理解本隐私政策。**一旦您开始使用本软件，即表示您已阅读、理解并同意本政策所述的所有内容。**

---

## 一、 基本原则

本软件在设计与开发过程中遵循以下核心隐私原则：

1. **最小必要原则**：我们仅收集和处理实现软件基础功能、保障系统安全及改善用户体验所必需的数据，绝不收集与服务无关的个人敏感信息。
2. **本地优先原则**：您的个人音乐库元数据、播放历史及偏好配置默认均保存在您的本地设备中，由您本人完全掌控。
3. **透明与可控**：我们致力于保持数据处理过程的公开透明，并为您提供便捷的数据管理与权限控制选项。

---

## 二、 我们处理与收集的信息

根据您使用的功能以及对软件的配置，我们处理的信息主要分为以下几类：

### 2.1 您主动提供的信息

- **第三方账户与服务连接凭据**：当您选择使用自建媒体服务器（如 Subsonic、Navidrome、Jellyfin、Emby 等）、绑定第三方平台账户（如 Last.fm）或配置 AI 模型时，您输入的服务器地址、用户名、访问令牌（Token）或 API 密钥。凭据优先通过操作系统原生安全机制加密并仅保存在本地；若系统安全存储不可用，流媒体密码和 Last.fm 会话密钥会退化为 Base64 编码保存，应用同时写入本地警告日志；AI 模型 API Key 则会拒绝保存。Base64 不等同于加密。凭据不会传输至任何开发者控制的服务器。
- **用户偏好配置**：您在软件中设置的界面语言、视觉主题、快捷键映射、音频输出设备配置等个性化参数。

### 2.2 本地运行与缓存数据

- **媒体库与播放数据**：您指定的本地文件夹扫描路径、音频文件元数据（曲名、歌手、专辑、流派等）、本地播放列表、歌词缓存及封面缩略图。
- **本地操作日志**：为了帮助您排查软件在运行过程中可能出现的故障，本软件会在您的本地设备中生成运行日志文件。该日志仅保存在您的设备本地，除非您主动提取并提交给开发者寻求帮助，否则不会被自动上传。

## 三、 信息的使用目的与合法依据

我们处理上述信息的目的严格限定于：

1. **提供核心播放与管理功能**：对您的本地或自建服务器音频进行解码、播放、展现歌词及呈现控制界面。
2. **保持您的个性化配置**：在您重新启动软件后还原您的使用习惯与设置。
3. **保障系统安全与稳定性**：我们在本地运行必要的安全防护机制，保障应用在您的设备上安全可靠地运行。

我们绝不会将您的任何数据用于广告推送、用户画像分析、商业营销，亦绝不会将您的信息出售或出租给任何第三方。

## 四、 第三方服务与开放扩展免责声明

为了丰富音乐播放体验，本软件支持接入多种第三方服务与开放插件。**请您理解，此类第三方服务均由其各自的运营方独立提供与运营：**

1. **自建与个人媒体服务器**：当您通过本软件连接个人部署或有权访问的媒体服务器时，相关网络通信直接发生于您的客户端与该服务器之间。相关服务器中的数据安全与隐私保护由您及该服务器的运营方自行负责。
2. **第三方插件与音源扩展**：本软件提供开放的插件接口和可选的插件市场。市场收录会经过自动检查与维护者审核，但这不构成完整的安全审计或背书。第三方插件仍由社区或独立开发者开发与维护，可能包含独立的网络请求与数据处理行为；您在导入和使用前应核实来源、权限与代码风险。
3. **第三方平台集成（如 Discord RPC / Last.fm）**：当您开启 Discord 状态展示或 Last.fm 播放打卡功能时，软件将通过本地 IPC 端口或官方 API 与对应平台交互。相关数据的处理同时受该第三方平台自身的用户协议与隐私政策约束。

## 五、 信息的存储、保存期限与安全防护

### 5.1 存储位置与保存期限

- 您的绝大部分数据均存储于您本地设备的数据目录中。
- 只要您继续使用本软件，相关配置与缓存数据将一直保存在您的本地设备上，直到您主动清除或卸载本软件。

### 5.2 数据安全防护措施

我们采取符合行业标准的技术手段与安全保护措施，防止您的信息遭受未经授权的访问、泄露、篡改或损坏：

- 敏感账号凭据优先采用系统级原生安全存储进行加密保护；流媒体密码和 Last.fm 会话密钥的 Base64 降级会明确记录警告，AI 模型 API Key 在安全存储不可用时不会保存。
- 软件内部采用受控的安全沙箱与进程隔离机制，防止恶意脚本注入。
- 涉及网络传输的环节优先采用 HTTPS/TLS 等加密传输协议。

### 5.3 风险提示

尽管我们采取了合理的安全措施，但请您理解，由于计算机网络与电子存储技术的固有局限性，**没有任何系统能够保证 100% 的绝对安全**。您应当妥善保管您的设备安全及第三方账号凭据。

## 六、 您的权利与数据管理

您对自己的个人信息与本地数据拥有完全的管理权限：

1. **访问与查阅**：您可以随时通过软件设置界面或直接打开本地数据文件夹，查阅所有存储于本地的数据库与配置文件。
2. **更正与更新**：您可以在软件设置中随时修改您的偏好参数、自建服务器信息或第三方绑定。
3. **清除与删除（被遗忘权）**：
   - 您可以通过软件内部的“清除缓存/重置设置”选项删除指定的本地记录。
   - 您可以随时删除本地应用数据目录（数据路径可在设置中查看），或在卸载本软件后手动清理该目录，以永久彻底销毁本软件在您设备上留下的所有数据。
