# 插件使用指南

SPlayer-Next 支持通过插件扩展**音源**（解析歌曲的播放地址）与**控制**（联动播放状态、反向控制播放）。本文面向最终用户，介绍如何安装、启用与管理插件。想自己写插件，见 [插件开发](/plugins/)。

## 打开插件管理

**设置 → 插件管理**。每个已安装插件以卡片展示：名称、版本、作者、运行状态与支持的音源。

## 安装插件

两种方式，效果相同：

- **本地导入**：选择一个 `.js` 脚本文件。
- **在线导入**：粘贴一个指向 `.js` 脚本的 `http(s)` 链接（如 GitHub / Gitee 的 raw 地址）。

部分作者会以 `gz_` 前缀分发压缩脚本，SPlayer-Next 会**自动识别并解压**，无需额外操作。

## 启用 / 禁用 / 卸载

- 新安装的插件会**自动启用**。
- 在卡片上可随时启用或禁用插件；当多个插件支持同一音源时，由 SPlayer-Next 按优先级自动选用。音源插件之间互斥（同时仅一个生效），控制插件可同时启用多个。
- 控制插件若声明了设置项，可在卡片上打开**设置**进行配置。
- **卸载**会删除脚本及其本地数据，且不可恢复。

状态徽章：**已就绪**（可用）、**加载中**、**错误**（卡片下方会显示原因）、**已禁用**。

## 兼容 lx 插件

SPlayer-Next 兼容 [lx-music-desktop](https://github.com/lyswhut/lx-music-desktop) 的 user_api 脚本，多数公开的 lx 脚本可直接导入使用。若脚本用到了不常见或较新的 lx 接口，可能会加载失败。

## 常见问题

**导入后状态显示「错误」？**
查看卡片下方的错误信息，通常是脚本本身的语法 / 运行错误，或脚本声明的 API 级别高于当前版本（需等待应用升级）。

**插件崩溃会影响应用吗？**
不会。插件运行在独立沙箱中，崩溃会被隔离并自动恢复，不影响主程序。

**插件请求很慢？**
插件的网络请求会遵循系统代理，速度取决于目标接口与网络状况。
